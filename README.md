# Шолоховский 3D

Мобильный 3D-прототип города с двумя районами: **Центр** и **Диетка**.

## Технологии
- Godot 4.4+
- GDScript
- Compatibility renderer для мобильных устройств

## Первая версия
- процедурная тестовая карта города;
- два района, соединённые главной дорогой;
- персонаж от третьего лица;
- сенсорное управление: левая сторона экрана — движение, правая — поворот камеры;
- кнопка прыжка.

## Запуск
Открой папку проекта в Godot 4.4 или новее и запусти главную сцену.
